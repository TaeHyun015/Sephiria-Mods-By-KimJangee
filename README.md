# Sephiria-Mods-By-김쟁이

저는 팀을 이뤄 개발을 하는 개발자가 아니며, 소스에 관한 것을 함부로 공개하는 것은 아직 Sephiria의 공식 모드 지원이 되지 않았기 때문에, 적용방법 및 설명만 적어두겠습니다.

I am not a developer who works in a team, and since official mod support for Sephiria hasn't been released yet, I'm reluctant to just disclose the source code. Therefore, I will only provide the application methods and instructions.

## 한국어

MelonLoader 기반으로 임시로 만들어진 Sephiria Mod 모음입니다. Harmony Patch 를 사용하는 모드도, 아닌 모드도 있습니다.
Sephiria 에서 정식적으로 모드를 지원하기 시작하면, 방식을 변형하여 재업로드 할 예정입니다.

### 적용법

모드를 적용하기 위해서는 MelonLoader 설치가 **필수**입니다. 아래 링크에서 MelonLoader 설치기를 다운로드 받아주세요.

[멜론로더 다운로드 받는 링크](https://github.com/LavaGang/MelonLoader/releases/download/v0.7.2/MelonLoader.Installer.exe)

다운로드 받은 후, MelonLoader 실행 파일에서 Sephiria 를 검색하여 적용해주세요.

적용한 이후, Sephiria 설치 폴더를 가보시면 Mods 폴더가 생겨있을겁니다.

dll 파일만 존재하는 파일은 그 폴더안에 그대로 붙여넣기 해주시면 되고, 압축파일은 압축을 풀어서 안에 있는 내용물을 Mods 폴더에 전부 넣어주세요.

## ENGLISH

This is a collection of Sephiria Mods temporarily created based on MelonLoader. Some mods use Harmony Patch, while others do not.
Once Sephiria officially starts supporting mods, I plan to modify the method and re-upload them.

### How to install

MelonLoader installation is **required** to apply mods. Please download the MelonLoader installer from the link below.

[Link to download MelonLoader](https://github.com/LavaGang/MelonLoader/releases/download/v0.7.2/MelonLoader.Installer.exe)

After downloading, search for Sephiria in the MelonLoader executable and apply it.

Once applied, you will see a Mods folder has been created in the Sephiria installation directory.

For files that are just .dll files, simply paste them directly into that folder. For compressed files, extract them and put all the contents into the Mods folder.
